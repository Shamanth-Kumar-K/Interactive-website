# Interactive Responsive Website

A **fully responsive and interactive website** built using **HTML, CSS, and JavaScript**, featuring:

- **Smooth Image Carousel**: Auto-slide with navigation dots and manual controls.  
- **Interactive Quiz**: 5 questions with real-time feedback, correct/incorrect highlights, and scoring.  
- **Dynamic Joke Generator**: Fetches jokes from a public API with a smooth fade-in effect.  

Designed with **modern UI enhancements**, **animations**, and **mobile-friendly responsive layouts**.

## ⚡ Features

1. **Responsive Design**: Works on mobile, tablet, and desktop using media queries.  
2. **Carousel**: Smooth transitions, auto-slide, clickable dots, pause on hover.  
3. **Quiz**: Bold, large questions, instant feedback, correct answer highlight, score display.  
4. **API Integration**: Fetches random jokes from the Official Joke API with animations.  
5. **Modern UI**: Gradients, hover effects, shadows, and smooth animations.
